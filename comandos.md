# comandos

## GIT

| comando                        | función                    |
| ------------------------------ | -------------------------- |
| git --version                  | ver la versión             |
| git init                       | inicia un git              |
| git add .                      | añade los archivos         |
| git commit -m "api node js 5%" | creamos la primera versión |
| git branch -M master           | rama de desarrollo         |
| git push -u origin master      | sube los cambios           |

## RUTA

`git remote add origin https://github.com/Rayitas-hue/API_NODE_3315298.git`
